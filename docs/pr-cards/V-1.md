## User outcome
Select an enrolled project and parent, name a run-owned branch, preview verified
monthly branch + compute cost and expiration, explicitly confirm within durable
owner spending caps, then list its run and clean *only* the owned development
branches. Cleanup reads the exact persisted run/object set, reclassifies every
provider branch as nonproduction/unprotected/unshared and refuses any unknown
child, stale/incomplete provider list or changed app ownership. Children are
soft-deleted first; expired branches are recognized from a full provider list.
Only independent absence marks a row cleaned. Lost/ambiguous writes remain
pending and are never replayed or inferred from an annotation.

  \`outsideApp:false\` at all preflight and last-moment app ownership checks.
  An app adoption always transfers deletion authority away from this run.

  provider create request. Only independently read-back matching annotation,

  foreign-project and repeated-cursor refusal; fail closed beyond 10,000

- Owner run inspection returns recorded branch IDs, parent, expiry and per-object
  cleaned state (subject to normal result shaping/handle limits).
- Unit regression uses vendored request-shape enforcement and tests ambiguous
  write recovery, paged enumeration, persistent annotations, protected/foreign
  run refusals, exact cleanup, and no bypass through outsideApp. This is source
