### B-3d estimated preview fallback (#28)
- `src/neon/sql-estimate.js` returns non-executing PostgreSQL `EXPLAIN` counts in `BEGIN READ ONLY`, only after trusted `ctx.verifyPreviewFallback` confirms `branch_limit` or `budget_exhausted`. The exact preview path defers only on those conditions; arbitrary API errors, DDL, protected projects or failed planning refuse safely.
- Database `change_log.sql_estimate` (default false) marks non-exact, hash/scope/expiry-bound one-use tokens; `consumeSqlPreview(... acceptEstimate)` refuses an estimate without consent and does not consume it. `applyGuardedSql` checks the marker and requires `acceptEstimate:true`, reporting actual count/read-back without falsely enforcing the inexact estimated count. Exact paths still roll back on one-row difference.
- New tests for estimate conditions, no writes, token consent and estimate apply; no real Neon LSN-restore verified before X-3.
