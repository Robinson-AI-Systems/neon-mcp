## Tests

- `tests/unit/fake-neon.test.js`: an undocumented path fails; a documented create-branch call is recorded with its
  operationId; operations go `running` → `finished`; a 423 then 200 sequence; a 429 sequence.
- `tests/unit/fixtures-valid.test.js`: every fixture in `neon-fixtures.js` validates against the description.
- `tests/unit/registry.test.js`: duplicate tool names throw.
- `tests/unit/check-secrets.test.js`: each planted pattern in a temp file fails (a `napi_` key, an `npg_` password, a
  `postgresql://u:p@ep-…neon.tech/db` URL, a real-looking endpoint host); `napi_FAKE…`, `npg_FAKE…` and
  `postgresql://user:FAKE@localhost/db` pass.
- `tests/unit/check-core-imports.test.js`: a planted `src/core/x.js` importing `@neon/sdk` fails (temp directory).
- `tests/db/contract.test.js`: the database contract runs on throwaway Postgres.
