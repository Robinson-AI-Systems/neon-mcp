## Verified API and seams
- `GET /projects/{project_id}/snapshots` → `listSnapshots`, `{snapshots:[Snapshot]}`; Snapshot has id/name/created_at and optional source_branch_id/manual/full_size/diff_size.
- `GET /projects/{project_id}/branches/{branch_id}/backup_schedule` → `getSnapshotSchedule`, `{schedule:[BackupScheduleItem]}`, with bounded frequency/retention/time fields.
- `getProject` independently confirms project ID and organization, `listProjectBranches` confirms all branch IDs for schedules; use only the project-scoped verified key, projectRead, defineReadTool, and existing dispatcher. Empty/over-limit/unverified source must not be disguised as complete. Source branch of a historical snapshot may no longer exist and should remain an ID, not falsely claimed currently active.
